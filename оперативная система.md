Я бы хотел создать ОС для обычных людей. Назову её AuraOS. Она нужна для повседневных задач: работы, учебы, игр и интернета. Главная фишка — она должна быть максимально понятной, чтобы не нужно было лезть в настройки.

Начинал бы я не с написания ядра, а с интерфейса. Сначала сделал бы простой макет, как все будет выглядеть, а потом уже писал код.

Из технологий взял бы ядро от Linux, потому что оно бесплатное и безопасное. Для самой графики (окон, кнопок) использовал бы Qt.

Языки программирования: Rust — для безопасности системы. C++ — для работы с железом и драйверами. Python — для разных встроенных программок.

Насчет интерфейса. Я бы сделал его по умолчанию как на Mac — минимализм, красивый док внизу, все понятно. Но при этом добавил бы встроенную программу, через которую любой юзер мог бы в пару кликов поменять этот интерфейс. Хочешь как в Windows с панелью задач? Пожалуйста. Хочешь как в Linux? Легко.

Вдохновлялся я Mac (за красоту), Windows (за игры и софт) и Linux (за свободу). Просто взял бы лучшее от каждой и собрал в одну.

В итоге, AuraOS — это система, которая не навязывает правила, а подстраивается под человека.
